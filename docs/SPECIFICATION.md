# [Kalvatar] AI 일정 자동화 및 위치 기반 실시간 캐릭터 소셜 앱 기획서 (v1.1)

---

## 1. 프로젝트 개요

### 1.1 프로젝트 목적
- **단순 기록을 넘어선 행동 중심 일정 관리**: 기존 캘린더가 "언제 무엇을 해야 하는가"를 기록하는 수동적 도구였다면, 본 서비스는 자연어로 입력된 일정을 분석하여 **"그 일을 시작하기 위해 언제부터 무엇을 준비해야 하는가"**까지 실행 루틴을 자동 생성하고 리마인드합니다.
- **실시간 위치 & 활동 기반 캐릭터 소셜**: 친구 간에 부담스러운 텍스트 소통 대신, 지도 위에서 실시간으로 이동하고 현재 행동을 표현하는 **아바타(캐릭터)**를 통해 일상을 자연스럽게 공유하고 가볍게 상호작용(응원/리액션)합니다.

### 1.2 핵심 가치 체인
```
[Schedule] 무엇을 할 것인가 (자연어 일정 등록)
   ↓
[Automation] 실행을 위해 무엇을 준비할 것인가 (AI 행동 루틴 & 알림)
   ↓
[Location & Activity] 어디서 무엇을 하고 있는가 (스마트 상태 판별 & 선택적 위치 추적)
   ↓
[Character Avatar] 현재 상태를 어떻게 시각화할 것인가 (지도 위 이동 및 활동 애니메이션)
   ↓
[Social Interaction] 친구와 어떻게 연결할 것인가 (가벼운 인터랙션 & 리액션)
```

## 2. 주요 기능 및 상세 정책

### 2.1 자연어 일정 등록 및 AI 분석
- **입력 방식**: 복잡한 필드 입력 대신 단일 자연어 텍스트/음성 입력창 제공
  - *예시*: "월, 수, 금 저녁 7시에 역삼 헬스장에서 1시간 웨이트 운동"
- **AI 분석 항목 (LLM Function Calling / Structured Output)**:
  - 일정 카테고리 (운동, 업무/회의, 공부, 병원, 약속, 이동 등)
  - 시작 및 예상 종료 시간
  - 반복 주기 (요일, 격주 등)
  - 목적지 장소 (위치명, 주소, 좌표)
- **사용자 확인 절차**: 파싱된 결과를 카드 뷰로 렌더링하여 사용자 최종 확인(수정 가능) 후 DB 저장.

### 2.2 AI 행동 루틴 자동 생성
- 일정 카테고리와 장소 거리를 계산하여 전/후 행동 루틴을 시계열로 자동 생성:
  - **18:20** 운동 준비 알림 ("운동복 및 프로틴 챙기기")
  - **18:40** 이동/출발 알림 ("현재 위치에서 헬스장까지 도보 18분 소요")
  - **19:00** 활동 시작 & 타이머 구동
  - **20:00** 활동 종료 및 완료 체크인/기록 유도
- 생성된 각 루틴 단계는 사용자가 개별 알림 시간 및 내용을 커스텀/삭제 가능.

### 2.3 일정 유형별 외부 연동 정책
- OS 보안 정책(iOS App Sandbox, Android Background 제한)을 준수하여 강제 실행 대신 **원터치 딥링크/인텐트/알림 액션**으로 구현:
  - `[지도 길찾기]` (카카오맵, 네이버지도, Apple Maps)
  - `[음악/플레이리스트 열기]` (Spotify, Apple Music)
  - `[앱 내 타이머]` (집중 타이머, 운동 세트 타이머)
  - `[체크인 완료]` (상태 즉시 전환)

## 3. 위치 기반 실시간 캐릭터 지도 (핵심 차별점)

### 3.1 지도 상의 실시간 아바타 표현
- 단순한 지도 핀(Marker) 대신, 사용자가 커스텀한 **캐릭터 아바타**가 지도 좌표 상에 위치.
- **이동 애니메이션**: 좌표 갱신 시 순간 이동이 아닌, 이전 좌표와 최신 좌표 간 보간(Interpolation)을 통한 부드러운 이동 경로 애니메이션 제공.
- **활동 상태 오버레이**: 캐릭터 머리 위/주변에 현재 행동 아이콘 및 미니 뱃지 노출.

### 3.2 활동 상태 라이프사이클 (스마트 상태 판별)
캘린더 시간만으로 상태를 단정하지 않고, **[시간 + 지오펜싱(장소 도착) + 사용자 체크인]**을 종합 판별:
```
[일정 대기] (18:30) 
   ↓ 출발 알림 / 이동 감지
[이동 중] (18:40~19:00, 도보/차량/대중교통 등 이동 아이콘 + 지도상 이동)
   ↓ 장소 도착(지오펜싱) or 사용자 시작 버튼
[활동 중] (19:00~20:00, 헬스장 도착 시 🏋️ 운동 애니메이션 전환)
   ↓ 사용자 완료 or 종료 시간 초과
[활동 완료 / 휴식] (20:00~)
```

### 3.3 캐릭터 선택 시 활동 상세 카드
- 지도에서 친구 캐릭터 터치 시 바텀시트(Bottom Sheet) 모달 오픈:
  - 친구 닉네임, 프로필 캐릭터 확대 뷰 (활동 전용 애니메이션)
  - 현재 활동명 ("헬스장에서 운동 중", 진행 시간: 32분 경과)
  - 장소 정보 (설정된 공개 범위에 따라 대략적/구체적 표기)
  - **퀵 리액션 버튼**: 불꽃(🔥 힘내!), 커피(☕), 파이팅(💪), 하트(❤️) 전송 시 친구 캐릭터에 팝업 효과 발생

## 4. 위치 공유 최적화 및 배터리/개인정보 보호 정책

### 4.1 현실적인 위치 공유 라이프사이클 (배터리 & 권한 최적화)
- **항시(24시간) 추적 지양**:
  - 일상적인 상태에서는 기기의 위치 정보를 과도하게 수집하지 않음.
- **공유 세션 활성화 조건**:
  1. 루틴에 의한 '이동 시작' 및 '활동 진행' 시간대 (예: 활동 시작 전 30분 ~ 활동 종료 시까지)
  2. 사용자가 수동으로 '실시간 위치 공유 켜기'를 누른 세션 (1시간/오늘만/활동종료까지)
- **적응형 업데이트 빈도 (Adaptive Polling)**:
  - **정지 상태**: 장소에 머무를 때는 5~10분 간격 하트비트 체크
  - **이동 상태 (Significant Motion)**: 가속도/이동 감지 시 10~30초 단위 좌표 수집
  - **친구 뷰어 유무**: 해당 친구의 지도를 열어보고 있는 친구(WebSocket 구독자)가 있을 때 정밀 브로드캐스팅

### 4.2 개인정보 보호 및 4단계 공개 범위
1. **정확한 위치 (Precise)**: 좌표 그대로 지도 상에 핀 및 경로 표시 (절친, 가족 대상)
2. **대략적인 위치 (Approximate)**: 반경 약 500m~1km 수준의 동 단위 원형 영역으로 마스킹
3. **활동만 공개 (Activity Only)**: 위치 좌표는 숨기고 "🏋️ 민수: 운동 중" 텍스트와 상태만 표시
4. **완전 비공개 (Ghost Mode)**: 지도 및 친구 목록에서 오프라인 처리
- **민감 장소 안심존 (Safe Zone)**: 집, 회사, 학교 등 사용자가 지정한 장소 반경 내 진입 시 자동으로 좌표를 숨기고 "🏠 집에서 휴식 중"으로 대체.

## 5. 시스템 아키텍처 및 기술 스택

### 5.1 기술 스택
- **Mobile Client**: React Native, TypeScript, React Native Maps, Reanimated 3 (캐릭터 애니메이션), Expo / Notifee (로컬/푸시 알림)
- **Backend API**: Java 17 / 21, Spring Boot 3.x, Spring Security (JWT), Spring Data JPA, QueryDSL
- **Database & Cache**:
  - **MySQL 8.0**: 회원, 친구 관계, 일정, 루틴, 활동 이력 등 영속성 데이터 (ACID 보장)
  - **Redis 7.x**: 
    - 사용자 최신 위치 캐시 (GeoHash / Redis GEO)
    - 실시간 세션/접속 상태 (Online/Offline)
    - WebSocket 세션 라우팅 및 Pub/Sub 브로드캐스팅
- **AI Engine**: OpenAI API / Google Gemini API (Structured Outputs를 통한 JSON 파싱)
- **인프라**: Docker, AWS (EC2/ECS, RDS, ElastiCache), GitHub Actions CI/CD

### 5.2 데이터 흐름 (실시간 위치 및 상태 동기화)
```
[User App (GPS)] 
      │ (HTTPS POST / WebSocket)
      ▼
[Spring Boot Backend] ──(최신 좌표/상태 저장)──▶ [Redis GEO / In-Memory]
      │
      ├─(Pub/Sub 발송)
      ▼
[WebSocket Handler / STOMP Broker]
      │
      ▼ (실시간 좌표 & 활동 이벤트 전송)
[Friend App (Map View)] ──▶ [Reanimated 보간 처리 & 캐릭터 이동]
```

## 6. MVP 개발 범위 (Scope)

| 구분 | 포함 기능 (MVP In-Scope) | 제외 기능 (MVP Out-of-Scope) |
|---|---|---|
| **계정 & 친구** | 소셜 로그인, JWT 인증, 친구 요청/수락/차단, 공개 범위 설정 | 복잡한 주소록 자동 동기화, 그룹 채팅 |
| **일정 & 루틴** | 자연어 일정 입력, LLM 분석, 행동 루틴 자동 생성 및 로컬 알림 | 타 캘린더 양방향 실시간 동기화, 복잡한 반복 규칙 예외 처리 |
| **위치 & 지도** | 지도 위 친구 캐릭터 표시, 부드러운 위치 이동, 활동 카드, 리액션 전송 | 실시간 이동 궤적(히스토리) 재생, 교통정보 반영 길안내 |
| **상태 & 캐릭터** | 기본 6대 활동 (운동, 업무, 공부, 식사, 이동, 휴식) 캐릭터 애니메이션 | 캐릭터 의상 상점, 아이템 거래, 유료 결제 시스템 |
| **개인정보** | 대략적/정확/활동만/비공개 설정, 집/회사 안심존 설정 | 다중 안심존 지오펜스 폴리곤 고급 편집기 |

## 7. 단계별 개발 로드맵 (Phased Roadmap)

- **Phase 1: 기반 아키텍처 및 핵심 데이터 (Week 1~2)**
  - Spring Boot 프로젝트 세팅, MySQL 스키마 구축, JWT 인증 및 친구 관계 CRUD
  - React Native 프로젝트 세팅 및 네비게이션 구조화
- **Phase 2: AI 일정 & 루틴 자동화 (Week 3~4)**
  - LLM 자연어 파싱 파이프라인 구축 (Prompt Engineering & Schema Validation)
  - 루틴 생성 알고리즘 및 푸시/로컬 알림 스케줄러 구현
- **Phase 3: 실시간 위치 & 지도 캐릭터 렌더링 (Week 5~6)**
  - Map SDK 연동, 캐릭터 마커 렌더링 및 Reanimated 보간 애니메이션 적용
  - Redis 최신 좌표 캐싱 및 WebSocket STOMP 프로토콜 구현
- **Phase 4: 소셜 인터랙션 & 최적화 (Week 7~8)**
  - 활동 카드 및 실시간 리액션 팝업
  - 위치 수집 배터리/권한 최적화, 비공개/안심존 필터링
  - 통합 테스트 및 모니터링 구축
